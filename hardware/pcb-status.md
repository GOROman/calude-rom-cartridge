# PCB 設計状況 (EasyEDA Pro プロジェクト: calude-rom-cartridge)

## 完了

- 回路図: 54部品・129ネット、ネット名スタブ方式で全結線。ERC エラー0/警告3
- PCB へネット取込済み(部品はパッドのネットで自動識別)
- 基板外形: 実績基板ガーバー実測の段付き形状 100.33×40.64mm + エッジタン
- エッジフィンガー: フリーパッド60枚(1.8×7.62mm、ピン1のみ8.89mmロング、ネット割当済)
- ゾーン配置: 595列(上段)/541列(中段)/245(下段左)/SRAM(下段)/M5Stamp(右上)/ゲート・抵抗(右)
- ベタ: TOP=+5V、BOTTOM=GND (タン部を除く全域、優先度1)

## 残作業

1. **配線**: EasyEDA Pro GUI で 布線 → 自動布線(クラウド)を実行、または手動配線
   - 優先: バッファ↔SRAM↔フィンガーの RUN 経路を短く
2. **DRC**: 配線後に実行(金フラッシュ 1mm クリアランスルール含む)
3. **シェルねじボス穴**: 実物シェルで位置を実測して追加(現状穴なし=摩擦保持)
4. **3D/シェル干渉確認**: M5Stamp S3 (高さ4.5mm) はシェル厚側キャビティに配置済み
5. **製造出力**: ガーバー生成 → JLCPCB (1.2mm厚 / ENIG or 金フラッシュ+ベベル指定)

## PCB上のリファレンス対応

回路図とPCBのデザイナタは自動採番のため、論理名↔ネットで識別する:
U_PRG/U_CHR=SRAM、S_*=74HCT595、B_*541/B_*245=バッファ、G_OR=HCT32、
G_AND=HCT08、G_INV=HCT04、M1=M5Stamp S3、J2=DA15ケーブル、JP1=ミラーリング
