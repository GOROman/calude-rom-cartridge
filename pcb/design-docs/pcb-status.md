# PCB 設計状況 (EasyEDA Pro プロジェクト: calude-rom-cartridge)

## 完了

- 回路図: 54部品・129ネット、ネット名スタブ方式で全結線。ERC エラー0/警告3
- PCB へネット取込済み(部品はパッドのネットで自動識別)
- 基板外形: 純正段付きプロファイル 90×56.8mm、板厚1.2mm。タン78.4mm/肩46.1mm/サイドノッチy20.9-22.9mm
- エッジフィンガー: フリーパッド60枚(1.8×7.62mm、ピン1のみ8.89mmロング、ネット割当済)
- LED追加: 電源LED(緑D1、+5V常時点灯)+ステータスLED(赤D2、GPIO14駆動)、R15/R16(330Ω)
- **配置最適化**: 接続クラスタ順(CHR系=左、PRG系=右、バッファをフィンガー寄り、シフトレジスタ上段、パスコンをIC隣接)でラッツネスト短縮
- **片面(TOP)実装**(リフロー前提): 全ICをTSSOP/TSOP化。M5Stamp右上(中心78.9178,20.32mm、USB右向きrot90)、パスコンを各ICに隣接配置。USB外形端をケース右内壁から0.66mm内側に合わせ、全銅箔端は基板内に保持。53部品を穴/ノッチ/境界/重なりゼロで機械検証済み
- GreenPAK U21 (SLG46826G/TSSOP-20) をPCB2のM5Stamp左側に追加。PCBパッドへ
  D0-D7、A0、RW、M2、+5V、GND、5V側I2C、OPM制御ネットを割当済み
- ベタ: TOP=+5V、BOTTOM=GND (本体領域、ノッチ回避多角形、優先度1)
- 穴: ネジ穴φ3@(39.5,19.8mm)、中央φ5@(45,10.3mm) NPTH配置済み

## 残作業

1. **配線**: EasyEDA Pro GUI で 布線 → 自動布線(クラウド)を実行、または手動配線
   - 優先: バッファ↔SRAM↔フィンガーの RUN 経路を短く
2. **DRC**: 配線後に実行(金フラッシュ 1mm クリアランスルール含む)
3. ~~シェルねじボス穴~~ → NESdev準拠位置で配置済み(実物シェルで最終確認推奨)
4. **3D/シェル干渉確認**: M5Stamp S3 (高さ4.5mm) はシェル厚側キャビティに配置済み。USB-C開口付き上シェルは `Dendy_top_usb.stl`
5. **製造出力**: ガーバー生成 → JLCPCB (1.2mm厚 / ENIG or 金フラッシュ+ベベル指定)
6. **GreenPAK周辺**: BSS138×2、I2Cプルアップ4本、C28、/OPM_CSデコード回路は
   回路図・PCBとも未配置。追加後にI2C/OPM制御ネットを物理配線してDRC

## PCB上のリファレンス対応

回路図とPCBのデザイナタは自動採番のため、論理名↔ネットで識別する:
U_PRG/U_CHR=SRAM、S_*=74HCT595、B_*541/B_*245=バッファ、G_OR=HCT32、
G_AND=HCT08、G_INV=HCT04、M1=M5Stamp S3、J2=DA15ケーブル、JP1=ミラーリング
