## 基板適合判定 ✓

現行基板(90mm幅 × 56.8mm高、タン78.4mm)は本ケースに収まる:

- 基板幅 **90mm** = ケース底部コネクタ領域 **90mm** に一致(±45)
- タン **78.4mm**(±39.2)はスロット開口(±45)内に収まり、コンソール接点が届く
- 基板高 **56.8mm** < 内部キャビティ **62mm**(ラベル部の余裕あり)
- 基板幅 90mm < 内部キャビティ幅 96mm

## M5Stamp S3 / USB-C位置

- M1中心: 基板座標 **(78.9178, 20.32)mm**、回転 **90°**（USB右向き）
- STL座標変換: `stl_x = pcb_x - 45`、`stl_y = 11.5 - pcb_y`
- USB-C開口中心Y: STL座標 **-8.82mm**
- M1のUSB側外形端: 基板座標 **X=92.342mm**。ケース内壁 **X=93mm相当** から内側へ約0.66mm
- キャステレーションとテストパッドの銅箔端は基板右端 **X=90mm** 内に収まる

## PCB位置決めピン穴(STL検出・準拠済み)

下シェルSTLの左右位置決めピン中心はケース原点基準で
**(-37.9, -2.59)mm / (+37.9, -2.59)mm**。ピン根元は約φ2.2mmで、
先端に向かって細くなるテーパー形状。

PCB2ではEasyEDAの左上原点座標で次の非メッキ穴を配置している:

- `LOC_L`: **(7.10, 24.79)mm、φ2.50mm**
- `LOC_R`: **(82.90, 24.79)mm、φ2.50mm**

穴径にはピン根元に対して片側約0.15mmの挿入クリアランスを設けている。
