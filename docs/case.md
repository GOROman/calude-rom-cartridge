STL: `pcb/case/thing-3357677/files/Dendy.stl`(下シェル)、`Dendy_top.stl`(上シェル)。画像・README・LICENSEも同梱。作者 5rw。

## 基板適合判定 ✓

現行基板(90mm幅 × 56.8mm高、タン78.4mm)は本ケースに収まる:

- 基板幅 **90mm** = ケース底部コネクタ領域 **90mm** に一致(±45)
- タン **78.4mm**(±39.2)はスロット開口(±45)内に収まり、コンソール接点が届く
- 基板高 **56.8mm** < 内部キャビティ **62mm**(ラベル部の余裕あり)
- 基板幅 90mm < 内部キャビティ幅 96mm

## M5Stamp S3 / USB-C位置

- M1中心: 基板座標 **(78.9178, 20.32)mm**、回転 **90°**（USB右向き）
- STL座標変換: `stl_x = pcb_x - 45`、`stl_y = 11.5 - pcb_y`
- USB-C開口中心Y: STL座標 **-8.82mm**
- M1のUSB側外形端: 基板座標 **X=92.342mm**。ケース内壁 **X=93mm相当** から内側へ約0.66mm
- キャステレーションとテストパッドの銅箔端は基板右端 **X=90mm** 内に収まる

## ネジ穴(STL検出・準拠済み)

STLの垂直円柱特徴を検出: **対称な2穴 (±2.6, -11.9)mm(ケース中心原点)、径2mm、高さ5mm**。
基板座標へ変換(board_x=STL_x+45、board_y=STL_y-11.5 ※タンのショルダー46.1mm↔スロット面):
- 基板穴: **(42.4, -23.4)mm と (47.6, -23.4)mm、径2.2mm** に配置済み
- X方向はケース中心対称で確実。Y方向はメッシュからの位置合わせのため±数mmの不確実性あり → 3D/現物で最終確認推奨

## 残確認(3Dで要検証)

- **ネジ柱/穴の位置合わせ**: STL内部の柱クラスタは (±48,20)/(0,-12)付近に検出。基板の穴(φ3@39.5/19.8mm, 中央φ5@45/10.3mm)と厳密一致するかは3Dビューで確認推奨
- EasyEDA Pro の3Dビューに本STLを取り込んで、基板と重ねてクリアランス/ネジ位置を目視確認するのが確実
- 3Dプリント品のため実測公差あり。発注前に現物合わせ推奨
