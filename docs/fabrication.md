# 製造仕様 (JLCPCB発注)

EasyEDA PCB2から生成した製造データは
[`pcb/fabrication/`](../pcb/fabrication/) にあります。ファイル構成は
[`pcb/README.md`](../pcb/README.md) を参照してください。

## 基板仕様

| 項目 | 指定 |
|---|---|
| 外形 | 純正段付き 90 × 56.8 mm(タン78.4mm/肩46.1mm/サイドノッチ深4.5mm@y20.9-22.9mm) |
| 層数 | 4層(L1=信号、L2=GNDベタ、L3=+5Vベタ、L4=信号) |
| **板厚** | **1.2 mm**(ファミコン仕様。1.6mm不可) |
| 表面処理 | **金フラッシュ(硬質金)+ 30°ベベル** 推奨(最低ENIG) |
| エッジフィンガー | 一辺のみ(下端)、60端子を同一幅1.600mm、先端テーパー、金メッキ、1mm以内に部品/ビア禁止 |
| 挿入側外形 | 左右下角 R1.524mm。ケースとの嵌合を現物確認 |
| 穴 | ネジ穴φ3@(39.5,19.8)/中央φ5@(45,10.3) NPTH |
| シルク | 両面(TOP=型番/値/コピーライト) |

## 実装

- 全IC/SRAM: TSSOP/TSOP、**片面(TOP)リフロー**
- M5Stamp S3: TOP面右上、USB右向き、手はんだ(キャステレーション/ヘッダ)
- ミラーリング: **JP1を垂直(V)に設定**(対象ゲームは垂直ミラー)

## 発注前チェックリスト

1. [ ] **エッジコネクタのピン1左右向き(鏡像)を実カートで確認** — 最重要。GND/+5V逆挿し防止
2. [ ] 自動配線(EasyEDA GUI)→ DRC クリーン(金フラッシュ1mmルール含む)
3. [ ] 3Dビューで M5Stamp とシェルの干渉確認
4. [ ] ガーバー生成後、発注画面で**完成板厚1.2mm・4層**を指定
5. [ ] 純正シェルに現物合わせ(外形・穴位置・タン厚)
6. [ ] 端子先端テーパー、左右下角R、30°ベベルの加工可否をPCBメーカーへ確認

## 構成部品(マッパー)

NROM(Mapper0)+ CNROM(Mapper3)両対応。CNROMバンクラッチ=U19(74HCT173)。
対象ゲーム `GOROman/calude-famicom-game`: CNROM/PRG32KB/CHR16KB/垂直ミラー。
