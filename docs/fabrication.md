# 製造仕様 (JLCPCB発注)

## 基板仕様

| 項目 | 指定 |
|---|---|
| 外形 | 純正段付き 90 × 56.8 mm(タン78.4mm/肩46.1mm/サイドノッチ深4.5mm@y20.9-22.9mm) |
| 層数 | 2層(TOP=+5Vベタ / BOTTOM=GNDベタ) |
| **板厚** | **1.2 mm**(ファミコン仕様。1.6mm不可) |
| 表面処理 | **金フラッシュ(硬質金)+ 30°ベベル** 推奨(最低ENIG) |
| エッジフィンガー | 一辺のみ(下端)、金メッキ、1mm以内に部品/ビア禁止 |
| 穴 | ネジ穴φ3@(39.5,19.8)/中央φ5@(45,10.3) NPTH |
| シルク | 両面(TOP=型番/値/コピーライト) |

## 実装

- 全IC/SRAM: TSSOP/TSOP、**片面(TOP)リフロー**
- M5Stamp S3: TOP面右上、USB右向き、手はんだ(キャステレーション/ヘッダ)
- ミラーリング: **JP1を垂直(V)に設定**(対象ゲームは垂直ミラー)
